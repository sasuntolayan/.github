# Special repository

GitHub treats a repository named `.github` in a personal account as a special repository. This repository is expected to be public, and GitHub uses what it holds for purposes that include defaults for the account's repositories.

## Defaults for the account's repositories

Some files tell people how to work with a repository, such as how to report a bug or how to contribute. When a repository of the account doesn't have its own version of one of these files, GitHub uses the one kept here instead.

The defaults that can live here include:

- Issue templates: what people fill in when they open an issue, and the page where they choose which kind of issue to open.
- Pull request template: what people fill in when they open a pull request.
- Discussion forms: what people fill in when they start a discussion in a given category.
- Contributing guide: how people can take part in the work.
- Code of conduct: how people are expected to behave towards each other.
- Support guide: where people can get help.
- Security policy: how to report a security vulnerability.
- Vulnerability report form: what people fill in when they privately report a security vulnerability.
- Accessibility statement: the accessibility goals, the known barriers, and how to report an accessibility problem.
- Funding: the sponsor button, which shows how people can support the work with money.
